# To-Do Game

A simple and interactive To-Do List game built with **ReactJS** and **Vite**.  
Add, complete, and remove tasks while tracking your progress, making your work a little more stress free.

## Instructions to Run Project

Go to the folder where your project is saved 
cd todo-project
npm install
npm run dev
open local host in browser

Type a task in the input box and click Add
Click on arrows to move tasks up and down based on priority
Click Delete to remove a task
Your tasks are automatically saved using localStorage
